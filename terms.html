Personal use

This utility is configured solely for the owner’s accounts and projects. It does not provide a public account, paid storage plan, or backup service to others.

The owner maintains access to the dedicated storage account and a separate copy of the recovery key. Backup availability depends on the configured computer, internet access, storage quota, and authorization. A successful upload must be checked with a recovery test before relying on it.

The utility does not authorize production deployments or financial trading actions. Recovery takes place in a separate empty directory before any existing project or running service is changed.
