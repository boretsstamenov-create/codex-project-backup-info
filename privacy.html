Privacy

Updated 1 November 2026.

The utility accesses Google Drive only with the owner’s authorization, to create encrypted backups, list and check restore points, download backups for recovery, and expire old backup versions under the configured retention policy.

Project contents are encrypted locally by restic before upload. The recovery key stays with the owner. Google OAuth tokens are stored in the owner’s local protected configuration and are not published on this website.

Google user data is not sold, used for advertising, or supplied to third parties for independent purposes. Backup files are stored in the owner’s dedicated Google Drive account. The owner can revoke the application’s access through Google Account settings and delete backup files through Google Drive.

Codex Project Backup’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This informational website does not collect Google user data. GitHub Pages serves the website and may process ordinary hosting request information under GitHub’s privacy policy. For contact, use the support email shown on the Google authorization screen.
